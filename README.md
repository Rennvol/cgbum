# CGBUM — Mihon extension

Source: https://cgbum.com — `src/id/cgbum` (HttpSource, Jsoup)

Install di Mihon: Settings → Browse → Extension repos → Add `https://raw.githubusercontent.com/Rennvol/cgbum/main/repo/index.min.json`
Atau download APK dari Actions → build → cgbum-apk.

Selectors: `article.comic-card` daftar, `.chapter-grid a.ch-grid-item` chapter, `#readerImages img[data-url]` reader (cdn8.cgbum.com).
